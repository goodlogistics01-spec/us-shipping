# 30-day evidence-led content plan

Internal planning document. Nothing in this schedule is permission to publish an unverified claim, customer identity, route result, photograph or testimonial.

## Publishing rules

- Each item needs a named source owner and the listed evidence before drafting.
- Use neutral operation photos only when the source and public-use permission are recorded.
- Keep receiving checks separate from separately agreed product-quality inspection.
- Do not add fixed transit times, rates, savings, coverage, warehouse ownership or credentials without current source records.
- If evidence is not ready, move the item to the next cycle rather than publishing a thin page.
