# Transit-time evidence requirements

Internal release checklist. This file does not authorize a public timing claim.

## Current public status

No route-specific numeric transit-time range is supported by the current approved materials. The sea-freight page therefore does not publish a large generic timing section. Current schedules remain shipment-specific until the evidence below is supplied and dated.

Two owner-provided working statements remain unpublished: air freight described as “as fast as 2–4 days to receipt,” and ocean freight described as “pickup 12–14 days after vessel departure.” Neither statement defines the route, cargo, day type, included stages or operating conditions, so both remain `TODO_CONFIRM / DO NOT PUBLISH` rather than public averages or guarantees.

## Minimum source record

Each proposed public range needs all of the following:

- a current carrier or provider schedule, dated quotation, or completed-shipment record that Good Logistics is permitted to use;
- the exact route, freight mode and cargo category;
- an explicit start and end event;
- the conditions and exclusions that materially change the range;
- the evidence date and owner responsible for rechecking it;
- publication approval for any shipment-specific result or supporting image.

Until those fields are complete, quote the current shipment instead of publishing a fixed number of days.
